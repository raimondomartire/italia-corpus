# Glossario

| Termine | Significato nel presente sistema |
| --- | --- |
| Agente | Il sistema di intelligenza artificiale dedicato, preimpostato su una singola società, oggetto di questa libreria |
| Allucinazione | Produzione da parte del sistema di un'informazione non presente nella documentazione e non corrispondente al vero, esposta con la medesima sicurezza delle informazioni corrette |
| Blocco | Funzione automatica che impedisce la prosecuzione dell'analisi in presenza di documentazione mancante o difforme; costituisce controllo di completezza formale e non procedura di revisione |
| Istruzioni permanenti | Regole configurate a livello di sistema, valide per ogni interazione, che vincolano il comportamento dell'agente |
| Livello di autorizzazione | Insieme delle schede utilizzabili da un componente del team in funzione della sua seniority |
| Output | Qualunque contenuto prodotto dall'agente; costituisce sempre bozza non verificata |
| Perimetro chiuso | Configurazione in cui l'agente accede esclusivamente alla documentazione dell'incarico, senza accesso libero né a dati di altri incarichi |
| Prompt | Richiesta formulata all'agente secondo la struttura prevista da questa libreria |
| Scheda | Unità della libreria, identificata da un codice, comprensiva di documenti da allegare, prompt, output atteso e verifica richiesta |
| Struttura R-C-C-V-F | Ruolo, Contesto, Compito, Vincoli, Formato |
| Test di affidabilità | Verifica periodica indipendente del corretto funzionamento dell'agente secondo il protocollo di cui a [`03-governance-qualita-e-monitoraggio.md`](03-governance-qualita-e-monitoraggio.md) |
| Verifica documentata | Riscontro dell'output sulle fonti primarie, di cui resta traccia nel fascicolo |
