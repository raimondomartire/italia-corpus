# Allegato — Regole di verifica per tipologia di output

| Tipo di output | Verifica minima obbligatoria |
| --- | --- |
| Riconciliazione tra due fonti | Ricalcolo integrale; riscontro dei due saldi sui documenti originali |
| Ricalcolo (ammortamenti, interessi, TFR, imposte, covenant) | Ricalcolo integrale autonomo; verifica dei dati di input |
| Estrazione o selezione da dati | Verifica della logica su un sottoinsieme di controllo con esito noto; verifica dei totali di quadratura dell'estrazione |
| Elenco di anomalie | Esame documentale di ogni elemento prima di qualificarlo come rilievo |
| Analisi di stime | Ricalcolo integrale; verifica delle assunzioni sui documenti; sensitività ricalcolata |
| Bozza di documento contrattuale o a firma | Revisione integrale parola per parola |
| Bozza di comunicazione | Revisione integrale; verifica che ogni fatto riportato sia riscontrato |
| Informazione di contesto o settoriale | Non utilizzabile come evidenza; riscontro su fonte indipendente |
| Riferimento normativo o a principi | Verifica sul testo vigente; in caso di dubbio, eliminazione |
| Elenco di rischi o scenari | Nessuna riduzione senza valutazione del team; l'output è input alla discussione |

Questa tabella va letta insieme alla checklist di [`01-principi-generali-e-regole-di-utilizzo.md`](01-principi-generali-e-regole-di-utilizzo.md) (§ I.7 e § I.10): individua **quale** verifica minima è dovuta in funzione del tipo di output, mentre la checklist descrive **quando** eseguirla nel flusso di lavoro.
